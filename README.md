# NiXOA

**Xen Orchestra, packaged as a focused NixOS appliance for XCP-ng.**

NiXOA turns one XCP-ng virtual machine into a reproducible Xen Orchestra
appliance.

```text
XCP-ng pool  →  NiXOA virtual machine  →  Xen Orchestra web interface
```

## What you get

- Xen Orchestra Community Edition with NFS, CIFS, VHD, and VHDX support
- repeatable, reviewable configuration
- atomic upgrades and rollbacks
- a guided console and a small command-line tool

NiXOA has one supported target: an `x86_64` XCP-ng guest named `nixoa`.

## Use

Open Xen Orchestra at `https://<vm-address>/`. The default certificate is
self-signed.

Connect to the appliance with `ssh nixoa@<vm-address>`, then use:

| Command | What it does |
|---|---|
| `nixoa-menu` | Opens the appliance console |
| `nxcli status` | Shows appliance health |
| `nxcli apply --dry-run` | Previews a configuration change |
| `nxcli apply` | Builds and activates the configuration |
| `nxcli rollback --ask` | Returns to the previous generation |

## Configure

Configuration lives in three files:

| File | Owner |
|---|---|
| `host/settings.nix` | Your durable settings |
| `host/hardware-configuration.nix` | Generated hardware and filesystem settings |
| `host/menu.nix` | Overrides generated by `nixoa-menu` |

Edit `host/settings.nix` for lasting changes. Do not hand-edit
`host/menu.nix`; the console rewrites it.
