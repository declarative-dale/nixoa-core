# NiXOA

**Xen Orchestra, packaged as a focused NixOS VM appliance for XCP-ng.**

NiXOA turns a NixOS virtual machine into a reproducible Xen Orchestra
appliance.

```text
XCP-ng pool  →  NiXOA virtual machine  →  Xen Orchestra web interface
```

## What you get

- Xen Orchestra Community Edition with a repeatable, reviewable configuration
- atomic upgrades and rollbacks
- a guided console and a small command-line tool

## Quick deploy

With Nix, Git, an authenticated GitHub CLI (`gh auth login`), an SSH public
key, and access to the XCP-ng pool master:

```bash
git clone https://github.com/declarative-dale/nixoa-core.git
cd nixoa-core

nix run --accept-flake-config .#deploy-template -- \
  --host XCP_POOL_MASTER \
  --iso-sr "ISO library" \
  --sr "Local storage" \
  --network "VM network" \
  --export-network "VM network" \
  --template-name NiXOA \
  --operator-key ~/.ssh/id_ed25519.pub
```

The command downloads the latest verified installer, prompts for missing
XCP-ng details, builds a sealed template, and never stores the XCP-ng password.
Clone the resulting `NiXOA` template, attach a NoCloud config drive containing
the operator SSH key, and boot it. See [installation](docs/installation.md) for
prerequisites, alternate paths, and local installer builds.

## Use

Open Xen Orchestra at `https://<vm-address>/`. The default certificate is
self-signed.

Connect to the appliance with `ssh nixoa@<vm-address>`, then use:

| Command | What it does |
|---|---|
| `nixoa-menu` | Opens the appliance console |
| `nxcli status` | Shows appliance health |
| `nxcli apply --dry-run` | Previews a configuration change |
| `nxcli apply` | Builds and activates the configuration |
| `nxcli rollback --ask` | Returns to the previous generation |

## Configure

Configuration lives in three files:

| File | Owner |
|---|---|
| `host/settings.nix` | Your durable settings |
| `host/hardware-configuration.nix` | Generated hardware and filesystem settings |
| `host/menu.nix` | Overrides generated by `nixoa-menu` |

Edit `host/settings.nix` for lasting changes. Do not hand-edit
`host/menu.nix`; the console rewrites it.
